# Global topological synchronization of weighted simplicial complexes

This repository contains the codes for global topological synchronization. These comprise two notebooks:

1. Global symchronization.ipynb: Notebook to visualize the spectrum of Laplacian and a special geometry.
2. MSF model.ipynb: Notebook to indicate that the weight assignment can able the weighted simplicial complexes to achieve global topological by plotting the growths of order parameters and temporal evolution.
